## S8 给料机头按质心停带（当前基线）

**改了什么**：S7 的基线唯一的失败来源是给料机头一次放下多块。TODO 第 1 节的三种改法都试了，采用改法二——头一块质心过机头 3 mm 就停带，让料自己翻（`--feeder-stop centroid`，现在是默认）；同时修了光束在质心过边前被挡时反复起停的缺陷。之前先修了两处让统计不干净的模型问题：相贴布料生成会把料摆进别的料（个别摆进挡边），数值筛查把料落地算成穿透超限。

**验收**：没见过的新种子 7201–7260，四种布料各 60 批，和旧线（S7 的线）在同一台机器上配对：

| 种子 7201–7260，240 批 | 旧线 | 当前基线 |
|---|---:|---:|
| 独立测成 / 投入 | 931 / 960（97.0 %，95.4–98.3） | **945 / 960（98.4 %，97.3–99.4）** |
| 错误有效测量 / 未测落仓 | 0 / 0 | 0 / 0 |
| 一次放下多块 / 有料过边的放料 | 93 / 865（10.8 %） | 36 / 924（3.9 %） |
| 需人工处理的批 | 16 | 8 |
| 清线均值 | 34.8 s | 36.6 s |

- 没测成的 15 块全部出自一次放下多块的 8 次放料，其中 5 次两块质心齐平（改前改后都是 14 次，机头分不开）；不齐平的一起放下 79 → 22 次，剩下的多是给料带停着时被翻下去的头一块拖过去的。
- 三种改法的小批（种子 7101–7130，各 120 批）：一次放下多块 43 次 → 慢走减半 21 次（慢 4.9 s）、按质心停带 10 次（慢 1.8 s）、光束抬高 30 次（另有 2 批 S1 长时遮挡停线）；光束"挪近机头"在回放里没有用。
- **证据边界**：给料控制器读真实质心，判"过边 3 mm"没有误差；实物上相机形心误差 p95 约 2.6 cm，这条规则落地前要有毫米级的过边检测（TODO 第 1、3 节）。其余和 S7 相同：未标定模型、计量装置是概念装置。

完整过程、表格和复现命令见 [S8 完整记录](../experiments/s8/REPORT.md)。

## S7 基线与结果（2026-10-05，旧线）

S7 的线 = 现在的线加 `--feeder-stop beam --set control.feeder.EARLY_BEAM_CREEP=0`（本机核对过逐批相同；S7 的数据跑在 Windows 上，逐批结局和 Linux 不全相同，见 S8 记录第二部分）。

**基线**：出口 0.60 m；给料读真实质心和轮廓；计量停稳后固定 1 s 出数；计量段、犁面仍读模拟传感器。每批 3–5 块，四种布料，单批时限 200 s。

**主指标** = 独立测量成功块数 / 全部投入块数。成功要求有效、未撤销、真值单块、无秤外接触、扫描有效；作废移除仍留在分母。稳定性、质量误差和正确落仓单列后续检查，完整定义见 [验收口径](../designs/station/DESIGN.md#独立测量验收口径)。

| 样本 | 有结果的批次 | 独立测成 / 投入 | 成功率 |
|---|---:|---:|---:|
| 修正后重跑，种子 7101–7130 | 118 | 461 / 472 | 97.7% |
| 未参与修正的新种子 7131–7160 | 119 | 471 / 477 | 98.7% |
| **合计** | **237** | **932 / 949** | **98.2%** |

- 共计划 **240 批**；3 批因初始布料重叠未运行，单列为无结果，不进入投入块数。合计成功率的原报告 95% 区间为 **96.9%–99.4%**（按批重抽 4000 次）。
- **未测成 17 块**：16 块多块同上秤，1 块圆料接触秤外，均作废停住；来自 9 次一次放下多块的放料，涉及 9 批人工处理。
- 错误有效测量、未测落仓、作废件放行均为 **0**；**228 / 237 批**全部独立测成。测成的 932 块均正确落仓，作为后续检查记录。

**证据边界**：这是未标定模型中的独立受测结果。前 118 批参与过 S1 误报修正，不能视作独立的新样本；实物测量精度、真实给料感知与产能尚未验证。不同阶段的配置、种子和指标不同，不能直接混合比较。

## 常用入口

在项目根目录运行：

```powershell
# 读取现有 S7 结果，不重跑物理仿真
python experiments/s7/s7_analyze.py experiments/s7/results/out_valid_b experiments/s7/results/out_valid_c --list

# 单批运行；结果保存到 runs/
python plough.py --seed 392 --count 5 --duration 150 --no-video

# 共用审计回归
python experiments/s7/s7_analyze_checks.py
```

普通结果优先看 `measurement_audit.counts`；错误标志看 `verification`，后续检查在 `later_checks`，批次总体状态在 `batch`。命令行与 S7 共用 `singulator/audit.py`；新跑批命令见 [实验目录索引](../experiments/README.md)。

新增试验把过程、完整表格和复现信息写入对应 `REPORT.md`；本页只更新当前基线、关键结论和明细链接。
