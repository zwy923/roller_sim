# 末端抬板式煤矸分流装置（独立模型）

用户确认：落板时煤沿板通过；检测到矸石后抬板，让矸石从缺口落下。板宽跟随前段传送带。
独立模型最初接在 1.20 m 宽的卸料带后面，所以默认板宽 **1.20 m**；线上的板跟随计量带是 0.70 m（卸料带随原主线在 2026-09-30 删除）。

2026-09-24 起：
- 几何代码（`Config`、`build`、`state`、`verify`、`material_clearance`）移到 `singulator/separator.py`（2026-10-05 起在 `singulator/machine/separator.py`），本目录的 `model.py` 只负责独立模型的渲染、交互窗口和输出文件。移动前后独立模型的输出逐字相同。
- 线上（见 [designs/station/DESIGN.md](../station/DESIGN.md)）把同一套零件接在计量带（称重 + 测体积）后面：
  - 板宽跟随计量带改为 0.70 m，纵筋按原间距排成 7 根；
  - 入口高度仍是 1.45 m，入口在带头后 2 cm，筋条顶比带面低 2 cm；
  - 板面衬 UHMW-PE（摩擦 0.20），因为 20° 落板上煤对钢板（0.45）会停住。
- 2026-09-30 起板的两侧有挡板（`Config.side_wall_height`，默认 0.25 m，厚 10 mm，装在板上随板翻；0 = 无）：没有挡板时，煤沿落板下滑会从侧边滑出去。

## 使用

在项目根目录运行：

```powershell
.venv\Scripts\python.exe designs\flip_separator\model.py
.venv\Scripts\python.exe designs\flip_separator\model.py --length 1.8 --open-deg 78
.venv\Scripts\python.exe designs\flip_separator\model.py --no-video --view
.venv\Scripts\python.exe checks\flip_separator_checks.py
```

交互窗口可转动视角，按空格切换落板 / 抬板。视频及交互窗口均为**规定角度的空载运动学演示**，不代表油缸能在该时间内带载完成动作。默认示意抬板、复位各 2 秒。
`--out` 可以另设输出目录，避免覆盖上一组模型。

默认输出在 `output/flip_separator/`：

- `model.xml`：可编辑 MuJoCo 装配，包含横向转轴、板体、固定纵筋、机架、轴承、液压缸铰接和伸缩副。
- `config.json`：参数、确认项、假设项、两种板位的连接点坐标。
- `closed.png`、`open.png`、`side_open.png`、`motion.mp4`：两种板位、侧视图、完整动作。
- `checks.json`：181 个角度的铰点闭合、缸行程、死点、启用碰撞的几何体穿透检查，以及球形料块包络的指定通道间隙检查。

## 暂定几何及连接关系

| 项目 | 当前值 | 依据 |
|---|---:|---|
| 板宽 | 1.20 m | 用户要求匹配前段；从现有卸料带配置读取核对 |
| 板长 | 1.60 m | 展示用暂定值，可用 `--length` 修改 |
| 落板 / 抬板角度 | 向下倾斜 20° / 75° | 图片外形参考，非测量值 |
| 转轴距入口 | 板长的 72% | 图片连接关系的暂定解释，可用 `--pivot-fraction` 修改 |
| 转轴到板面法向距离 | 0.24 m | 将轴和绿色支承移到板底，避免凸出输送面；可在 Config 中调整 |
| 入口高度 | 1.45 m | 独立机架展示高度，尚未与上游标高对接 |
| 板面长条 | 11 根固定纵筋 | 图片解释，用户尚未确认是否为其他构件 |
| 缸最短销距 / 总行程 | 0.80 m / 0.45 m | 几何演示参数，不是采购型号 |

坐标：x 向下游，y 横跨板宽，z 向上。翻板绕 y 轴转动，**入口端向上抬、出口端向下转**；转轴保持固定。
缸筒上端铰接在机架，活塞杆下端连接板下的耳座。缸伸长推动板转到抬板位；两个连接点通过真实铰接 / 伸缩自由度及闭环约束保持连接。
绿色连接臂先沿板底伸到机架侧外方，再向下接油缸销轴；不使用会在抬板时扫过轴承立柱的低位横穿杆。横向转轴通过板底支架连接板体，轴的上缘低于板底 182 mm（沿板法向），不穿出输送面。绿色连接臂和转轴现已启用接触。
蓝色半透明面只标示上游来料位置，不是有动力的传送带。板下保留落料空间，尚未建煤、矸石接料溜槽。

## 能确认什么

默认几何已通过编译和运动学检查；检查的是当前假设的机构是否装得上、能按指定轨迹运动。
轴承座、油缸及固定耳座细节和上游参考面不参与常规机器自碰撞检查，因此不能把“零穿透”理解为全部硬件间隙合格。

新增料块通道检查直接计算距离，**也检查关闭接触的油缸、支座外形**：使用直径 300 / 500 mm 球形包络，在宽度内左、中、右三个位置检查整个板面的 181 个角度；另检查落板时板面向外延伸的直通空间，以及抬板时从入口以 0.4 / 1.2 m/s 水平离开后在重力下的假定落料轨迹。仅检查球底高于地面 0.25 m 的区域，下面接料设备尚未建模。默认参数下未发现包络与硬件相交。

这些是明确限定路径的几何检查，不是带料动力学试验：煤离开板边的翻转、滑移、反弹，以及不规则块体姿态都未验证；煤的直通检查不能代替板边脱离过程的接触计算。300 / 500 mm 球形包络也不覆盖项目内所有不规则块体的最大卡尺尺寸。

MJCF 内保留活塞位置执行器用于后续动力学开发；力限 20 kN、位置增益、阻尼、材料密度和质量均为占位假设，不是油缸选型或强度计算。外部程序加载 XML 后应先 `mj_resetDataKeyframe(model, data, 0)`，再 `mj_forward`，以闭合的落板位初始化；第 1 个关键帧为抬板位。

**尚未验证带料分流。** 独立模型没有料块。完整结构里料块会经过排料板，由称重和测体积的密度判定抬板，但只跑过一次演示，没有做实验；没有宣称通过率、漏矸率或驱动力合格。
实际需要检查的失败情形包括：煤在静止斜板上停住、矸石被上掀入口顶住、矸石跨过缺口、复位夹料、相邻煤块在开板期间误落。20° 斜板能否让煤持续滑动，不能仅凭这两张图确定。
